# ÓGHOWA — Building Africa's Innovation Economy

> A high-performance, responsive React + TypeScript venture building web application inspired by the Óghowa ecosystem design. Ready for deployment on GitHub and Vercel.

## 🚀 Key Features

- **Pixel-Accurate Visuals**: Replicated layout hierarchy, typography (Plus Jakarta Sans), color palette (Deep Navy `#0A162B`, Oghowa Vibrant Red `#D9232A`), and component spacing directly from the design screenshots.
- **Complete Landing Page Experience**:
  - **Header**: Responsive navigation with brand emblem logo, "Programs" mega-dropdown, and direct action triggers ("Join Oghowa", "Login").
  - **Hero Section**: High-impact African venture building banner with the Benin heritage statue silhouette, auditorium summit background, eyebrow badge, and bottom audience ribbon (`FOUNDERS` • `INVESTORS` • `CORPORATES` • `GOVERNMENT` • `UNIVERSITIES` • `DEVELOPMENT PARTNERS`).
  - **Who We Serve**: 6 audience cards with responsive hover elevation and direct onboarding flows.
  - **The Oghowa Journey**: 6-stage lifecycle pipeline with interactive milestone inspection (Discover, Build, Validate, Fund [highlighted], Scale, Exit & Reinvest).
  - **Flagship Platforms**: 6 initiative cards linking directly to dedicated sub-pages.
  - **Infrastructure That Builds Businesses**: Deep-navy capabilities matrix covering Cloud, AI Platforms, Payments, Legal, BI, Logistics, Talent, Cybersecurity, and more.
  - **Our Impact**: 6 verified ecosystem metrics (`100+` Ventures, `₦500M+` Capital Facilitated, `5,000+` Members, etc.).
  - **Featured Ventures**: Startup showcase for active portfolio ventures (Ugbokhun, Edulida, Cyena Medicare, Future Ventures).
  - **Our Partners**: Logo badges for Edo State Government, UNIBEN, Sterling, Microsoft, AWS, MTN, Dangote, GIZ, Standard Chartered, and AFD.
  - **Pre-Footer CTA**: High-converting call-to-action banner.
  - **Footer**: Full multi-column navigation, legal links, and social channels.
- **Dedicated Program Pages (Screenshot 2 Replication)**:
  - **Oghowa Innovation Weekend** (54-hour sprint, hackathon details, participant categories)
  - **Oghowa Incubation Program** (3-6 months validation, mentorship, stages)
  - **Oghowa Venture Studio** (Co-building tech ventures, focus verticals, partner profiles)
  - **Oghowa Capital Network** (Angel syndicates, venture funds, blended finance)
  - **Oghowa Business Week** (Continental summit, keynotes, deal rooms, passes)
  - **Oghowa Research & Policy Lab** (Evidence-based policy briefs and startup acts)
- **Interactive Modals**:
  - `JoinModal`: Comprehensive application form with role selection (Founder, Investor, Corporate, University).
  - `LoginModal`: Portal sign-in modal.
  - `VentureModal`: Venture profile, key metrics, and founder connection trigger.

## 🛠 Tech Stack

- **Framework**: React 19 + Vite 6
- **Language**: TypeScript 5.8
- **Styling**: Tailwind CSS v4 with custom theme tokens
- **Icons**: Lucide React
- **Animations & Interactivity**: Smooth CSS transitions and state managers

## 📦 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Start the local development server
npm run dev

# 3. Build for production (outputs to /dist)
npm run build
```

## 🌐 Deploying to Vercel & GitHub

1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: initial Oghowa venture platform"
   git branch -M main
   git remote add origin https://github.com/your-username/oghowa-platform.git
   git push -u origin main
   ```
2. In Vercel, click **Add New Project**, import the GitHub repository, and select **Vite** as framework preset.
3. Deploy!
